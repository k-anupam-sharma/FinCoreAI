# SME WhatsApp Bot

This is a WhatsApp bot for managing your SME business data. It connects to Twilio and uses Python (FastAPI) to process messages.

## Setup Instructions

1. **Install Dependencies**
   A virtual environment is recommended.
   ```bash
   python -m venv venv
   .\venv\Scripts\activate
   pip install -r requirements.txt
   ```

2. **Start the Bot Server**
   Run the FastAPI server locally:
   ```bash
   python bot.py
   ```
   *The server will start on port 8000.*

3. **Expose Local Server to the Internet**
   Since Twilio needs a public URL to send webhooks, use [ngrok](https://ngrok.com/):
   ```bash
   ngrok http 8000
   ```
   Copy the HTTPS URL generated by ngrok (e.g., `https://<random>.ngrok-free.app`).

4. **Configure Twilio WhatsApp Sandbox**
   - Go to your Twilio Console -> Messaging -> Try it out -> Send a WhatsApp message.
   - Join the sandbox by sending the requested code from your WhatsApp to the Twilio number.
   - In the Sandbox settings, paste your ngrok URL with the endpoint: `https://<random>.ngrok-free.app/whatsapp` into the "When a message comes in" field.
   - Save the settings.

## Available Commands

Try sending these messages to your bot from WhatsApp:
- `help` - Show all commands
- `inventory PROD001` - Check the stock for a specific product
- `sales` - Get the total sum of all sales to date
- `expense|RENT|5000|Monthly rent` - Log a new expense (pipe-separated: expense|Code|Amount|Description)

## Project Structure
- `bot.py` - FastAPI app acting as the Twilio webhook handler.
- `data_manager.py` - Functions to query and manage the CSV datasets using pandas.
- `datasets/` - Contains the CSV files with your business data.
